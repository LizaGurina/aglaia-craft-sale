# Aglaia's Craft Sale

Сайт: <https://lizagurina.github.io/aglaia-craft-sale/>

Сайт-приглашение на 8-летие Аглаи: приглашение, фото, правила ярмарки, кнопка «будем» со счётчиком гостей и вишлист с сортировкой по цене. Статический сайт для GitHub Pages; общие данные (гости, занятые подарки) хранятся в Google-таблице.

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css`, `app.js` | сама страница |
| `config.js` | адрес Google-скрипта, дата, адрес праздника |
| `assets/` | фото (без GPS-меток), картинки из приглашения; `assets/st/` — стикеры, `assets/sea/` — небо, море, песок |
| `backend/Code.gs` | код для Google-таблицы |

Пока `apiUrl` в `config.js` пустой, сайт работает в **демо-режиме**: всё сохраняется только в браузере того, кто нажимал. Для настоящего общего счётчика нужен шаг 1.

## 1. Google-таблица (один раз, ~5 минут)

1. Создайте новую таблицу: <https://sheets.new>, назовите, например, «Aglaia craft sale».
2. Меню **Extensions → Apps Script**. Сотрите всё в `Code.gs` и вставьте содержимое `backend/Code.gs`. Сохраните (💾).
3. Сверху в списке функций выберите `setup` → **Run**. Google попросит разрешение: **Review permissions → ваш аккаунт → Advanced → Go to … (unsafe) → Allow**. Это ваш собственный скрипт, он работает только с этой таблицей. В таблице появятся листы **Guests** и **Gifts**.
4. **Deploy → New deployment** → шестерёнка → **Web app**. Execute as: **Me**. Who has access: **Anyone**. **Deploy** → скопируйте **Web app URL** (кончается на `/exec`).
5. Вставьте этот адрес в `config.js`: `apiUrl: 'https://script.google.com/macros/s/…/exec'`.

Если потом поменяете `Code.gs`: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. Иначе сайт продолжит работать на старом коде.

## 2. Вишлист — лист **Gifts**

Одна строка = один подарок. Сайт подхватывает изменения при обновлении страницы, перевыкладывать сайт не нужно.

| Колонка | Что писать |
|---|---|
| `title` | название (обязательно) |
| `price` | цена в евро: `12`, `12,50` |
| `link` | ссылка на магазин (необязательно) |
| `image` | ссылка на картинку товара (необязательно); без неё показывается `emoji` |
| `emoji` | значок на карточке, например 🎨 |
| `note` | короткое пояснение |
| `taken_by`, `token`, `taken_at` | заполняет сайт, когда гость нажал «I'll bring it» (имя гостя не спрашивается, пишется `a guest`). Можно вписать что угодно в `taken_by` вручную — подарок станет «занят» |
| `id` | можно оставить пустым, скрипт впишет сам |

После `setup` там уже весь вишлист Аглаи (40 подарков с Amazon: цена, ссылка, фото). Новый подарок — новая строка; удалить — удалить строку.

Когда гость нажимает «I'll bring it», подарок исчезает из списка у всех остальных; у самого гостя карточка остаётся с пометкой «Yours!» и кнопкой «undo».

## 3. Ответы гостей — лист **Guests**

Имя, сколько детей и взрослых, будут ли продавать поделки, записка для Аглаи. `coming = FALSE` — гость отменил ответ. Эти имена видны только в таблице: на сайте показываются только общие числа, а у подарков — только «занят / свободен».

## 4. Выложить на GitHub Pages

1. Создайте репозиторий, например `aglaia-craft-sale`. На бесплатном аккаунте GitHub Pages работает только с **публичным** репозиторием, значит файлы (включая фото) видны всем, кто найдёт репозиторий.
2. Загрузите туда все файлы этой папки, кроме `_preview/`.
3. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**. Через минуту сайт будет по адресу `https://<логин>.github.io/aglaia-craft-sale/`.
4. Превью ссылки для WhatsApp (фото Аглаи) уже прописано в `index.html` (`og:image`).

## Приватность

- Страница закрыта от поисковиков (`noindex`), но открыта всем, у кого есть ссылка.
- Из фото удалены метаданные, в том числе место съёмки.
- На одном фото ярмарки (`assets/market-room.jpg`) видны другие дети и взрослая. Если не хотите их показывать, удалите этот блок `<figure>` из `index.html`.
